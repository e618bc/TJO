# Формат ключа ответов

Один JSON-файл:

```json
{
  "author": "краткое имя роли",
  "vacancies": [
    {
      "id": "ID вакансии из входного файла",
      "is_clean": false,
      "expected": [
        {
          "topic": "title | duties | requirements | salary | schedule | location | employment",
          "type": "missing | ambiguity | contradiction",
          "fields": ["поле источника", "второе поле для противоречия"],
          "quotes": ["дословная цитата или значение поля", "вторая цитата для противоречия"],
          "importance": "core | accept",
          "note": "почему это проблема, одним предложением"
        }
      ],
      "must_not_flag": [
        {"topic": "тема", "note": "что выглядит подозрительно, но замечанием быть не должно, и почему"}
      ]
    }
  ]
}
```

- `core` — решение, которое это пропустило, теряет баллы.
- `accept` — замечание допустимо, но не обязательно; за его отсутствие баллы не снимаются.
- `must_not_flag` — за такое замечание баллы снимаются как за лишнее.
- Темы: title — название должности, duties — обязанности, requirements — требования, salary — оплата,
  schedule — график, location — место работы, employment — тип занятости.
- Для пропуска `quotes` пустой. Для противоречия в `quotes` два значения.
- У вакансии без проблем `is_clean` равно true, `expected` пустой.
